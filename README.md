# Frontend CV

**[View my CV online](https://roxy-92.github.io/frontend-cv/)**

A personal CV website built with Angular and TypeScript, available in English and Spanish.

## About

I built this project to present my frontend development profile in an interactive, accessible format rather than relying on a traditional PDF alone.

The website includes a language switch and a print-friendly layout designed to fit an A4 page.

## Technologies

- Angular
- TypeScript
- HTML
- SCSS
- Git and GitHub

## Features

- Bilingual content: English and Spanish
- Language switching
- Responsive layout
- A4-friendly print layout
- Automated deployment with GitHub Actions
- Hosted on GitHub Pages
